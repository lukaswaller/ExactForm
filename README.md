# ExactForm

TI-style exact-form calculator for phones: real fraction bars, surds, symbolic π/e, and an exact ⇄ decimal toggle. Everything Apple's calculator can't do, offline, no ads.

**Status:** Planning complete (vision, research, architecture, UI/UX). Build not started.
